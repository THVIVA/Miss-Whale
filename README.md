# Miss-Whale
- 一只住在你桌面上的鲸鱼小姐（大肥鱼）。
- 喂她吃饭、陪她发呆、一起养鱼、带她旅行，慢慢收集她的 61 篇日记。
- 同时可以监控你的桌面版Deepseek Harness每日消费token及余额。

- 点击右侧Releases下载`Miss Whale.zip`，解压后双击 `Miss Whale.exe` 即可。
- 无需安装任何额外内容。

#特性#

- 区别于其他单纯放置&监控数据的Deepseek开源桌宠，内置了更多丰富的玩法与收集内容。
- 包括但不限于：
- ·无边框桌宠：包含基础动画、拖拽动画、互动动画等。
- ·养成系统：等级与饱食度、好感度系统，可随着游戏时长提升等级及解锁更多内容。
- ·商店系统：包含金币消费与游戏内道具玩法。
- ·鱼塘系统：包含*类种田*养成玩法，收集鱼苗并培育，培养更多的鱼类赚取金币与制作美食！
- ·烹饪系统：包含十几种烹饪食材与菜谱玩法，可以自己制作喜欢的菜肴。
- ·扭蛋系统：可以花费金币与特殊扭蛋币进行抽奖，内置多种特殊玩法道具。
- ·图鉴系统：内置61张游戏cg及日记故事（可解锁内容），一边跟鲸鱼小姐生活一边尝试解锁全部内容吧！

#游玩说明#

- 到 [Releases](../../releases) 下载 `Miss Whale.zip` 并解压。
- ⚠️ **不要放在 `C:\Program Files`** —— 桌宠无法获取写入权限。
- 双击 `Miss Whale.exe`即可游玩。
- 仅支持 **Windows** 系统运行。
